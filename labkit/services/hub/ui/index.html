Kiro MCP servers

  1. Open this repo folder in Kiro. It reads .kiro/settings/mcp.json.
  2. In the Kiro panel, open MCP servers. You should see labkit-ping, labkit-atlassian, labkit-grafana, labkit-db.
  3. Ask Kiro: "Call the labkit ping tool." It should answer pong.
  4. If the servers do not start, use full paths: copy the config below into .kiro/settings/mcp.json.

      
No MCP at all? Every tool also works from the command line: node labkit/cli.mjs atlassian, node labkit/cli.mjs grafana, node labkit/cli.mjs db.
